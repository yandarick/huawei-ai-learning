# 02 · 昇腾硬件入门

## 第一组概念

### Ascend / 昇腾
华为 AI 计算体系的核心品牌与技术平台。

### NPU
Neural Processing Unit，针对神经网络计算设计的处理器。

### Atlas
华为基于昇腾构建的 AI 计算产品体系之一。学习时需要区分“芯片/处理器”和“板卡、服务器、集群产品”。

### SuperPoD
超节点。核心思想不是简单把很多服务器放在一起，而是通过高速互联和系统级设计，让大量计算单元更紧密协同。

## 学习重点

不要先背所有型号。先学会回答：

1. 一块 NPU 在哪里？
2. 一台服务器有多少 NPU？
3. NPU 之间怎么通信？
4. 服务器之间怎么通信？
5. Scale-up 与 Scale-out 有什么区别？
